# Le Løgin Client

## Building

The .NET project invokes the client build with its selected version and asset directory.
For a standalone build, pass both arguments explicitly:

```bash
pnpm build 18.0.0-rc.1 ../obj/v18/Debug/net10.0/client/wwwroot/App_Plugins/le-løgin
```

The command builds in staging, replaces each output file atomically, then publishes the
package manifest last. It does not change `public/umbraco-package.json`.

## OpenAPI client generation

The OpenAPI client is generated by `scripts/generate-openapi.js`.
The generation pipeline also applies post-generation type fixes from the script itself,
so generated files stay clean without manual edits.

### URL resolution

The generation script resolves the OpenAPI URL in this order:

1. first CLI argument
2. `OPENAPI_URL` environment variable
3. local default (`https://localhost:44312/umbraco/openapi/le-løgin-api-v1.json`) when not running in CI

In CI (`CI=true`), no localhost default is used. You must provide `OPENAPI_URL` or pass the URL explicitly.

### Local TLS behaviour

For local development, the script allows self-signed TLS only when the selected URL is on `https://localhost...`.
It does not disable TLS verification for non-local hosts.

### Local default endpoint

When no URL is provided locally, generation targets:

- `https://localhost:44312/umbraco/openapi/le-løgin-api-v1.json`

### Generate client

Optional commands:

```bash
# Default endpoint (44312)
pnpm generate-client

# Override with environment variable
OPENAPI_URL=https://localhost:44322/umbraco/openapi/le-løgin-api-v1.json pnpm generate-client

# Override with explicit argument
node scripts/generate-openapi.js https://localhost:44322/umbraco/openapi/le-løgin-api-v1.json

# CI-style invocation
OPENAPI_URL=https://example.test/umbraco/openapi/le-løgin-api-v1.json CI=true pnpm generate-client
```

### Post-generation safeguards

Generation applies lightweight post-processing to generated output to remove known generator noise (for example, stale TODO comments), while keeping changes in the generator pipeline rather than manually editing generated files.

### Validation

After generation, run:

```bash
pnpm lint
pnpm test:unit
pnpm build 18.0.0-rc.1 ../obj/v18/Debug/net10.0/client/wwwroot/App_Plugins/le-løgin
```
